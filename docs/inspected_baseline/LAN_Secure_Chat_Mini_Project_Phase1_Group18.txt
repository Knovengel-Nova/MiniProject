THE PROBLEM
Typical messaging platforms depend on external infrastructure and are 
designed for Internet-scale communication. For a classroom, office LAN or 
isolated lab, that can add unnecessary dependency and reduce local 
control over data.
WHY IT MATTERS
Users need fast local messaging, file exchange and searchable history 
while keeping communication inside the trusted network boundary. 
Security research also shows that secure messaging must balance 
confidentiality with usability.

SARDAR PATEL INSTITUTE OF TECHNOLOGY  ·  DEPARTMENT OF COMPUTER ENGINEERING P2 · GAP ANALYSIS
Gap Analysis
The project is not intended to replace Signal; it combines LAN-first architecture, relational persistence and lightweight PDS.
GROUP 18  ·  MINI PROJECT I  ·  2026–27 ODD SEM 06
System Network model Security Persistence Limitation / gap
Signal / WhatsApp Internet + servers Strong E2E Server / cloud Not LAN-first; large-scale infrastructure.
Telegram Internet + servers E2E only in Secret Chat Server-based Security model differs by chat mode.
BeeBEEP LAN / P2P AES-based Local history No integrated PDS layer; different architecture.
IP Messenger LAN / serverless RSA + AES + SHA Local logs Lightweight utility; limited analytics/DB integration.
Our proposal LAN + Java server TLS + protected storage PostgreSQL Adds interpretable PDS modules + unified DB design.
IDENTIFIED GAP A small, explainable, LAN-only academic system that integrates secure communication + PostgreSQL + PDS techniques in one demonstrable pipeline.

SARDAR PATEL INSTITUTE OF TECHNOLOGY  ·  DEPARTMENT OF COMPUTER ENGINEERING P4 · RISKS & VALIDATION
Risks and Validation
Phase 1 defines measurable acceptance criteria before implementation begins.
GROUP 18  ·  MINI PROJECT I  ·  2026–27 ODD SEM 12
Risk Mitigation / validation
LAN discovery fails Use fixed server IP / configurable discovery as fallback; test across multiple hosts.
Database bottleneck Use indexed message tables, prepared statements and pagination for history.
Security claim is too broad Clearly separate transport security, credential security and message-storage security.
Classifier false positives Report probability + threshold; allow user feedback and evaluate precision/recall.
Linear model is weak Use it only for a measurable short-term metric and report MAE/RMSE honestly.
Python–Java integration adds latency Run inference locally and exchange compact JSON requests/responses.
